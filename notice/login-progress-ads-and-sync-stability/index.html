업데이트 2026.10.20

v6.17.10 - 로그인 진행 표시·광고 로딩·동기화 안정화

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

로그인 진행 표시와 광고 로딩 문제를 개선하고, 구글 동기화와 단어 데이터 업데이트를 안정화한 v6.17.10을 배포했습니다. 불편을 겪으신 분들께 죄송하다는 말씀을 드립니다.

수정 및 개선 사항
로그인 진행 표시

화면 상단의 「로그인 필요」를 누르면 로그인이 진행 중임을 표시하도록 개선했습니다. 진행 중에 다시 눌러도 로그인이 중복으로 실행되지 않습니다.

광고 「Loading...」 반복 문제 수정

광고를 불러오지 못할 때 「Loading...」 표시가 계속 반복되던 문제를 수정했습니다. 광고를 불러오지 못한 뒤 앱으로 돌아오면 다시 불러오도록 개선했습니다.

화면 이동 문제 수정

화면을 오갈 때 수정 전 값이 남거나 의도하지 않은 화면으로 이동하던 문제를 수정했습니다.

구글 동기화 안정화

구글 동기화를 안정화했습니다. 다시 로그인에 실패한 뒤 계정 선택 창이 뜨지 않던 문제와, 누르지 않았는데 계정 선택 창이 뜰 수 있던 문제 등을 수정했습니다.

단어 데이터 업데이트 안정화

일부 기기에서 단어 데이터 업데이트가 올바르게 진행되지 않을 수 있던 문제를 수정해 업데이트를 안정화했습니다.

접근성 개선

로그인 중에 스크린 리더가 진행 상태를 읽어 주도록 개선했고, Android의 발음 안내 배너를 스크린 리더가 버튼으로 인식하도록 개선했습니다.

항상 일단공부를 이용해 주셔서 감사합니다. 사용 중 불편한 점은 앱 스토어 리뷰를 통해 알려주세요.

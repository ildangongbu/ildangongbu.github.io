v6.17.3 - 자동 동기화 안정성 및 여러 문제 수정

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

자동 동기화 안정성을 강화하고 여러 크래시·버그를 수정한 v6.17.3을 배포했습니다.

수정된 문제
구글 로그인 버튼 눌렀을 때 앱 멈춤

구글 로그인 버튼을 눌렀을 때 앱이 멈추는(프리징) 문제를 수정했습니다.

자동 동기화 오작동 수정

앱을 오래 켜두면 자동 동기화가 로그인 만료 오류로 잘못 중단되던 문제와, 네트워크가 일시적으로 끊겼을 때 동기화가 실패로 잘못 표시되던 문제를 수정했습니다.

검색·퀴즈·단어 목록·메모 자동 복구

예전부터 앱을 사용해 온 일부 사용자에게서 단어 검색, 퀴즈, 단어 목록, 메모 수정이 되지 않던 문제를 수정했습니다. 업데이트 후 앱을 실행하면 자동으로 복구되며 기존 학습 데이터는 그대로 유지됩니다.

iOS 실행 속도 개선

iOS에서 앱을 실행할 때 첫 화면이 표시되기까지 오래 걸리던 문제를 개선했습니다.

검색 화면 강제 종료 수정

검색어를 입력한 직후 뒤로 가면 앱이 강제 종료되던 문제를 수정했습니다.

실행 멈춤·발음 오답 목록 표시 수정

일부 기기에서 앱 실행이 멈추거나 발음 오답 단어 목록이 비어 보이던 문제를 수정했습니다.

항상 일단공부를 이용해 주셔서 감사합니다. 사용 중 불편한 점은 앱 스토어 리뷰를 통해 알려주세요.

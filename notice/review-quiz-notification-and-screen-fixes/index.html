복습 퀴즈와 학습 알림, 화면이 닫히지 않던 문제 등을 수정한 v6.17.9를 배포했습니다. 불편을 겪으신 분들께 죄송하다는 말씀을 드립니다.

수정 및 개선 사항
복습 퀴즈 선택지 빈칸 문제 수정

복습 퀴즈에서 일부 단어의 오답 선택지가 빈칸으로 표시되던 문제를 수정했습니다.

학습 알림 설정 안정화

학습 알림 설정이 더 안정적으로 동작하도록 개선했습니다. 알림 시각을 처음 정할 때 알림 권한 요청이 빠지던 문제를 수정했고, 앱이 화면에 보이지 않는 동안 알림 권한 요청이 실패하면 앱으로 돌아왔을 때 한 번 다시 요청합니다.

결제 창·화면이 닫히지 않던 문제 수정

화면 아래에 안내 메시지가 떠 있으면 결제 창이나 일부 화면이 닫히지 않던 문제를 수정했습니다.

단어 수정 화면 개선

단어 수정 화면에서 키보드를 연 채 스크롤하면 저장 버튼이 밀려나던 문제를 수정했습니다. 저장에 실패하면 안내 메시지로 알려 드립니다.

접근성·문구 개선

메뉴 버튼의 열림·닫힘 상태를 스크린 리더에 전달하도록 개선했고, 한국어 설정 화면의 문구 띄어쓰기를 바로잡았습니다.

항상 일단공부를 이용해 주셔서 감사합니다. 사용 중 불편한 점은 앱 스토어 리뷰를 통해 알려주세요.

v6.17.5 - 계정 동기화 안전성 강화 및 접근성 개선

안녕하세요, 「JLPT 일본어 단어 공부, 일단 공부」 개발자 Deku입니다.

구글 계정과 데이터를 동기화할 때 발생할 수 있던 계정 혼선 문제를 집중적으로 수정하고, 설정 화면의 접근성을 개선한 v6.17.5를 배포했습니다.

새로워진 점
설정 화면 슬라이더 스크린 리더 지원 개선

설정 화면의 글자 크기·음량·속도 슬라이더를 스크린 리더로 더 명확하게 확인할 수 있도록 개선했습니다.

수정된 문제
다른 계정으로 전환된 상태에서 데이터가 섞이던 문제

기기에서 다른 구글 계정으로 전환된 상태일 때 동기화나 데이터 업로드·다운로드가 그대로 실행되어, 학습 데이터가 의도하지 않은 계정과 섞일 수 있던 문제를 수정했습니다.

동기화 중 로그인·로그아웃 시 계정 혼선

데이터 동기화 중에 로그인이나 로그아웃을 시도하거나 로그인이 자동으로 갱신될 때 발생할 수 있던 계정 혼선 문제를 수정했습니다. 로그인과 로그아웃을 짧은 간격으로 연달아 시도할 때 계정 상태가 꼬이던 문제도 함께 수정했습니다.

데이터 복원 중 로그인 만료 시 복원 실패

데이터를 복원하는 중에 로그인 정보가 만료되었을 때 로그아웃되거나 복원이 실패하던 문제를 수정했습니다.

가나 퀴즈 화면 앱 종료 문제 예방

가나 퀴즈 화면에서 발생할 수 있던 앱 종료 문제를 미리 방지했습니다.

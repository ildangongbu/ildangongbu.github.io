일당공부 v6.17.1 업데이트 안내

2026-06-30

이번 업데이트에서는 iOS 이용자분들이 겪으셨던 리뷰 관련 불편을 수정했습니다.

수정된 문제

iOS에서 리뷰 버튼을 눌러도 앱 스토어로 이동하지 않는 문제

리뷰 안내 팝업에서 OK를 눌러도 앱 스토어 리뷰 페이지로 이동하지 않는 문제가 있었습니다. iOS의 정책상 앱 내 리뷰 요청이 연간 최대 3회로 제한되어, 이 횟수를 초과하면 아무런 반응 없이 팝업만 닫히는 현상이 발생했습니다.

이제 OK 버튼을 누르면 앱 스토어 리뷰 페이지로 바로 이동합니다.

리뷰 후에도 리뷰 요청이 반복되는 문제

리뷰를 완료한 뒤에도 앱을 열 때마다 다시 리뷰 안내 팝업이 표시되는 문제가 있었습니다. 이제 한 번 리뷰를 남기시면 이후에는 팝업이 표시되지 않습니다.

항상 일당공부를 이용해 주셔서 감사합니다. 사용 중 불편한 점은 앱 내 문의 또는 앱 스토어 리뷰를 통해 알려주세요.

전체 JLPT N1~N5 단어와 음성 발음, 예문, 복습 기능을 일단공부 앱에서 만나보세요. 매일 적당한 분량의 단어 학습과 테스트, 약점 단어 자동 복습으로 일본어 단어 학습을 꾸준히 이어갈 수 있습니다.
